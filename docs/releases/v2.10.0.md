# v2.10.0

A minor release. One new experimental feature, off by default, and three fixes
to how a pinned account is retried. No user configuration migration is required.

Landed as [#681](https://github.com/ndycode/codex-multi-auth/pull/681),
[#682](https://github.com/ndycode/codex-multi-auth/pull/682) and
[#683](https://github.com/ndycode/codex-multi-auth/pull/683).

## Upgrade notes

No migration is required. Install the package and confirm the version:

```bash
npm i -g codex-multi-auth
codex-multi-auth --version
```

The command should report `2.10.0`.
