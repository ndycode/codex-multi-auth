# v2.12.0

A patch-shaped minor release. Effort suffixes now resolve to one key per model,
usage is priced by service tier instead of assuming standard rates, and a class
of lookup defect where a prototype member name was mistaken for a model id is
closed. No user configuration migration is required.

Landed as [#685](https://github.com/ndycode/codex-multi-auth/pull/685) and
[#686](https://github.com/ndycode/codex-multi-auth/pull/686).

## Upgrade notes

No migration is required. Install the package and confirm the version:

```bash
npm i -g codex-multi-auth
codex-multi-auth --version
```

The command should report `2.12.0`.
