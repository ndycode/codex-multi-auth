Light-terminal readability plus a full dependency and toolchain refresh: the login dashboard gains a terminal background mode (`auto`/`dark`/`light`), all five open Dependabot advisories are resolved, and the runtime now requires Node.js `22.19.0` or later. (#729, #730)

## Changed

- **Node.js floor raised to `>=22.19.0`** (was `>=18.17.0`): undici 8 and Vitest 5 both require Node 22, and Node 20 is end-of-life. If you run Node 18 or 20, upgrade Node.js first — see the upgrade guide. CI now tests on Node 22.x and 24.x. (#730)
- Runtime dependencies: `hono` 4.13.9 → 4.13.13, `ws` 8.21.3 → 8.22.0, `zod` 4.4.3 → 4.6.5, `undici` 6.29.0 → 8.11.2. (#730)
- Dev toolchain: Vitest 4 → 5.0.2, ESLint 10.0 → 10.12, typescript-eslint 8.56 → 8.71.1, lint-staged 16 → 17.6, fast-check 4.5 → 4.10, `@types/node` 20 → 26, `typescript-language-server` 5 → 6. TypeScript is split deliberately: `typescript` 6.0.3 keeps the JS compiler API (typescript-eslint, tsserver, tests) while `tsgo` (typescript 7.0.2, native compiler) runs `build` and `typecheck` via an explicit path so `.bin` link order can never silently select the 6.x checker. (#730)
- GitHub Actions pins moved to current SHAs: checkout v7, setup-node v7, upload/download-artifact v7/v8, codeql-action v4.38.2, hol-codex-plugin-scanner. `.nvmrc` → 22; the smoke job renamed `node18-smoke` → `node22-smoke`. (#730)
- `ProxyAgent` pins `allowH2: false` so undici 8's H2-by-default ALPN negotiation keeps the upstream wire protocol at HTTP/1.1, matching the 6.x line it replaces. (#730)

## Fixed

- Dashboard title, account labels, section labels, and help text are readable on light terminal themes such as Ghostty + Catppuccin Latte (#728): a persisted `uiColorMode` dashboard setting (`auto`/`dark`/`light`, default `auto`) editable under Settings → Theme → Terminal Background, a `CODEX_TUI_COLOR_MODE` process override, and `COLORFGBG` auto-detection pick light-mode foreground tokens. `auto` falls back to the historical dark styling when the terminal does not advertise its background, so dark-terminal output is unchanged. (#729)
- Light-mode tokens darken every foreground painted on the terminal background across truecolor (`#1e293b` heading, `#475569` muted, green-700/blue-700/amber-700/red-700 actions), ansi256, and ansi16 profiles; badge tables and `focusBg`/`focusText` pairs are untouched since they draw pale text on their own dark backgrounds. (#729)
- Muted prompt text no longer stacks the `dim` attribute on the muted foreground in light mode, which previously made secondary text faint again. (#729)
- Light-mode ansi16 `muted` uses normal black: bright black (`ansi16(90)`) maps to mid-gray in common palettes, which was the original contrast failure. (#729)

## Security

- All five open Dependabot advisories resolved — `npm audit` reports zero vulnerabilities: `source-map-js` <1.2.2 (high; indexed source-map offsets allow event-loop DoS), `brace-expansion` 4.x <5.0.12 (quadratic-time expansion ReDoS), `vitest`/`@vitest/mocker` 2.1.0–4.1.11 (redirect-mock path traversal / arbitrary file read), and `@humanfs/node` <0.16.8 (recursive copy follows symlinks outside the source tree). All five reach the repository through the dev graph only, not the published runtime. (#730)
- Security overrides refreshed and documented in `SECURITY.md`: `hono` pinned to `4.13.13`, `brace-expansion` to `5.0.12` via the `minimatch` override, `rollup` stays at `^4.59.0`; `undici` is now the exact-pinned `8.11.2` and drives the documented engines floor. (#730)
