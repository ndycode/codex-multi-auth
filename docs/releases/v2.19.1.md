Light-terminal readability: the login dashboard and menus gain a terminal background mode (`auto`/`dark`/`light`) so text painted directly on the terminal background switches to readable dark variants on light themes while badges and the focused row keep their own dark backgrounds. (#729)

## Fixed

- Dashboard title, account labels, section labels, and help text are readable on light terminal themes such as Ghostty + Catppuccin Latte (#728): a persisted `uiColorMode` dashboard setting (`auto`/`dark`/`light`, default `auto`) editable under Settings → Theme → Terminal Background, a `CODEX_TUI_COLOR_MODE` process override, and `COLORFGBG` auto-detection pick light-mode foreground tokens. `auto` falls back to the historical dark styling when the terminal does not advertise its background, so dark-terminal output is unchanged. (#729)
- Light-mode tokens darken every foreground painted on the terminal background across truecolor (`#1e293b` heading, `#475569` muted, green-700/blue-700/amber-700/red-700 actions), ansi256, and ansi16 profiles; badge tables and `focusBg`/`focusText` pairs are untouched since they draw pale text on their own dark backgrounds. (#729)
- Muted prompt text no longer stacks the `dim` attribute on the muted foreground in light mode, which previously made secondary text faint again. (#729)
- Light-mode ansi16 `muted` uses normal black: bright black (`ansi16(90)`) maps to mid-gray in common palettes, which was the original contrast failure. (#729)
