GPT-6.2 model support and runtime-helper lifetime hardening are now available in the latest release. (#769, #770)

## Added

- GPT-6.2 Sol and Astra model families are recognized across model resolution, request transformation, context limits, pricing, usage redaction, catalog fixtures, and the runtime wire path. (#769)
- Regression coverage protects GPT-6.2 aliases, context windows, pricing, and request behavior. (#769)

## Fixed

- The runtime helper keeps a verified owner alive for a bounded lease instead of allowing stale verification state to bypass the lifetime cap. (#770)
- Owner verification waits for an in-flight probe after wake-up, keeping helper shutdown decisions deterministic across timing boundaries. (#770)
