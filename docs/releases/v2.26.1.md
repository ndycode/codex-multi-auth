Native catalog discovery, login synchronization, and runtime rotation now handle recent Codex CLI changes safely. (#765, #766, #767)

## Fixed

- Rotation provider arguments are inserted before the command separator, preserving forwarded native CLI arguments. (#765)
- Native login changes are adopted by running state without losing account synchronization. (#766)
- Catalog probes use the installed Codex version, recover from rejected probes, and retry shared requests without stale version state. (#767)
